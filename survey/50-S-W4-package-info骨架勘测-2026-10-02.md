## 一 · 可复跑命令（本报告全部数字的来源）

```bash
cd /workspaces/Alice-mcbot
# ① 9 份文件 + 行数
find src -name package-info.java | sort | xargs wc -l
# ② 每份的 h1/h2/h3 骨架 + 每节行数（本报告 §二 的表就是它打印的）
python3 - <<'PY'
import re
from pathlib import Path
for f in sorted(Path('src').rglob('package-info.java')):
    rel=str(f).replace('src/main/java/com/dddgn/alice/','')
    lines=f.read_text(encoding='utf-8').split('\n')
    heads=[(i,l) for i,l in enumerate(lines) if re.search(r'<h[123]>',l)]
    print(f"═══ {rel}  总 {len(lines)} 行 · 结构标签 {len(heads)} 个")
    for k,(i,l) in enumerate(heads):
        nxt = heads[k+1][0] if k+1<len(heads) else len(lines)
        tag=re.search(r'<h([123])>',l).group(1)
        title=re.sub(r'^[ *]*<h[123]>','',l); title=re.sub(r'</h[123]>.*$','',title)
        print(f"   h{tag}  {nxt-i:3d} 行  {title}")
PY
```

**总量（实测）**：文件 **9** 份 · 合计 **598 行** · 结构标签（`<h1>`/`<h2>`/`<h3>`）**37** 个。
⚠️ **`<h1>`/`<h3>` 今天一个都没用** —— 37 个**全是 `<h2>`**。

## 四 · ⭐ 我建议的目标骨架（**8 个语义角色**，⛔ 不是 8 个必须凑齐的节）

> ⭐ **关键设计**：**"统一" = 每份文档的节**按同一批角色命名**，⛔ **不是让每份都凑齐 8 节**。
> 空节比缺节更坏（空标题会诱使人往里面灌水）。

| 角色 | 该装什么 | 今天有几份有 |
|---|---|---|
| **① 准入** | 谁能进来 / 进不来 | **6** |
| **② 定义 / 形状** | 这个包**是什么**（设计正文） | **7** |
| **③ 判据** | 为什么是这几件（机械可算优先） | **4** |
| **④ 禁令** | 明确不许什么（⛔ 含"什么不属于这里"） | **4** |
| **⑤ 回收条件** | 进来的东西**什么时候走** | **1**（只有 `staging/`） |
| **⑥ 门禁** | 哪道门禁盯着它（**写名字**） | **4** |
| **⑦ 沿革 / 未裁** | 从哪来、什么还没定、**修订史** | **8** |
| **⑧ 今天的状态** | 读数（**只有可复算的才写**） | **3** |

### ⭐⭐ 这个骨架与今天形状的**两处冲突**（⛔ 必须先裁，否则"统一"会走偏）

| # | 冲突 | 我的建议 |
|---|---|---|
| **C-A** | 角色 ④「禁令」今天装在**两个不同名字**下：「三条禁令」（`staging/`）与「什么不属于这里」（`compat/`）·「本包不负责的事」（`action/`）·「本包不装什么」（`region/`）—— **同一个角色 4 种写法** | ⭐ **合成一个节名**「**④ 本包 ⛔ 不做什么**」，**正文保留各自的说法**（⛔ 不改内容事实） |

### ⛔ 我**不建议**做的

1. ⛔ **不动正文事实**（用户已裁 (b)「承认它兼作包级准入 ＋ 设计」⇒ 内容是对的类型）
2. ⛔ **不给缺角色的包补空节**（`⑤ 回收条件` 只有 `staging/` 有 ⇒ 那是**对的**：回收条件是 `staging/` 的专属纪律）
3. ⛔ **不合并 `debug/` 与 `fixture/`**（两份标题相同但**判据不同**：`debug/` = 命令可达、`fixture/` = `item/` 引用也算开发期）

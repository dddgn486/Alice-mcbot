## 3 根因（分成三层，都是**事实层**，不是推测）

### 3.1 直接原因：**放置落进了"作业自己的通道必需格"**

`collect-drops` 的 `PILLAR/STEP_PLACEMENT` 把方块放进了**它自己刚挖出来、而且自己刚走过**的通道脚位格
（`(-65,54,181)` = unit 44 的脚位格）。放置前该格是空气、且是**主巷往返的必经格**（回程 `SPUR_RETURN` 的
目标就是沿这条支巷退回 `(-65,54,172)`）。
⇒ 用户看到的现象「**bot 被自己搭的方块拦住**」在日志里就是这个动作。

### 3.2 系统原因：那块圆石**按裁定永远不会被回收**

`WorldModLedger.recordPlacement` 第一条：
```java
// ⭐ D-398 R1/R2/R4：区外不记账（= 不承担恢复责任 = 不产生回收义务）。
if (ProtectionZones.isWild(level, pos)) { … skip … }        // isWild == !isProtected
```
矿洞这一带**没有保护区**（`isWild==true`）⇒ **不记账、不恢复** ⇒ 没有任何流程会拆掉它。
⚠️ 这**不是遗漏**：`WorldModLedger:165` 逐字写着「这是"区外一定不恢复"的直接推论，不是遗漏；
**要改就得改裁定本身**」（`D-398` R1/R2）。⇒ 想靠"记账 + 回收"来修，得先动这条裁定。

### 3.3 ✅ 已定（2026-09-25 深夜，用户描述现场 + 代码/谓词复算 + 离线夹具复现）：**是那条 `FALL` 边被自己的一格杀掉了**

用户对现场的逐字描述（**这一句把 3.3 从"未定"变成"可判定"**）：
「通道上方有一个矿簇，他搭路上去挖完后，自己被自己的方块挡住了，**没有特殊地形，就是封闭矿道**」。

于是几何被钉死（`-65,54,181` 是**通道最南一列的脚位格**，南9 = 单元 44 的末格），复原出来的**因果链**是：

| | `(-65,54,181)` = 空气（原状） | `(-65,54,181)` = 圆石（23:17:31.257 之后） |
|---|---|---|
| `appendFall` 的 drop=2 落点 | 空气 + 底下 `(-65,53,181)` 石头 ⇒ `canStandCentered` ✓ | `canWalkThrough` 假 ⇒ **该边消失** |
| 下落列净空 `(-65,55/56/57,181)` | 全空（bot 23:17:21~24 自己挖的 ✓） | 全空 ✓ |
| `fallRecoverable`（k=1..3 净空 + 放置面 + 一次性方块 ≥ 2） | ✓ | ✓ |
| ⇒ **零破坏的 `FALL` 边** | **存在** ⇒ 一步回家 | **不存在** |

被填掉之后**唯一剩下的出走口**是 `DESCEND → (-65,55,181)`（**圆石给了它地板，`canWalkOn(to)` 才成立**——
没有那块圆石，这个 DESCEND 也会被拒），而从那一格再往下进走廊需要
`canDescend` 的 `mid.above()` = `(-65,56,180)` 可穿 —— **那是天花板石头（整轮从没被挖过）** ⇒ 拒。
⇒ 搜索在"死胡同台阶"上耗尽（`nodes=3`），如实交 `UNREACHABLE`。

**离线确定性复现**（夹具 `channel_place_guard`，`ChannelPlaceGuardCheckTask`，同形拓扑）：
- 填圆石：`plan=UNREACHABLE nodes=3 movements=[]`（= 真机 `descend_precondition=11 status=UNREACHABLE nodes=3`）；
- 保住空气：`plan=REACHED movements=[FALL@脚位格, TRAVERSE@目标格]`（**零世界写入**）。

⚠️ **一个必须一起记下的边界**：`FALL` 边要求**手里一次性方块 ≥ 落差**（`fallRecoverable` 的
`countThrowaway >= drop`）。本夹具首版只给了 1 个圆石 ⇒ 量到的是"没材料"而不是"落点被自己堵掉"，
**一度把判据红成假**。真机那轮 bot 手里有圆石（刚放过一块、`[Recover]` 记了 4 次 PILLAR）⇒ 该边当时存在。

⇒ 原"需要一次探针"的判断**已被更强的证据替代**：真机计数 `descend_precondition=11` 与离线复现的
`nodes=3` 形状一致，且**唯一**被改变的自变量就是那一格的方块状态。

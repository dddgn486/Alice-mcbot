## 3. 结论（实验回答了什么）

1. ✅ **解释甲成立（"预算不够"，不是"没有路"）**：那个深矿**真的能到**。
   ⇒ **"深矿不可达 / 表示不了"这条假设被实验否掉**；`D-366b` 放开垂直动作缺守卫这件事**不是**卡死的成因。
2. ⚠️ **但不是"把预算调大就能用"**：要 **1.9M 节点（= 95× 预算）** 才找到一条 **88 段** 的路径，
   单次搜索 **14.9 s**；而同批另两个候选**连 2M 节点都打满仍未到**。
   ⇒ 把预算调到那个量级 = 每个 tick 卡 15 秒（本架构搜索同步跑在 tick 线程上）⇒ **绝对不可接受**。
3. ⚠️ **"按几何距离由近到远"没有预测力**（对 `A2` 的 `MAX_APPROACH_PLANS=3` 是**风险证据**）：
   最近的 #0/#1 **不可达（2M 打满）**，而第 3 个 #2 可达。
   ⇒ `A2` 的 cap=3 这次**恰好**覆盖到成功者（#2），但那是运气 —— 若成功者是 #5 就会漏掉。
4. ⭐ **未解机制（下一步的唯一目标）**：一条 88 段的路径，而"直接往下挖 4 格 + 横 5 格"的理论成本
   远低于它（≈10 段、成本 ≈26 vs 88 段 ≈97）⇒ **A\* 返回的不是最便宜的路**，这只有一种解释：
   **那条直挖路所需的边在该次搜索里没有被生成**（或定价高到不可比）。
   已知排除项：`yInBounds` = 全建筑高度（不是它）；`plannedWritesAllowed` 在**无作用域**时返回 true（不是它）；
   `goal_post_write_not_standable=1` 说明目标格**确实**是靠一条**写边**走进去的（写边存在，但只在终点附近出现）。
   ⇒ 下一步量：把返回路径的**动作类型直方图 + 总成本**打出来（一次 73 s 的探针即可），
   看那 88 步里有没有 `DOWNWARD` / `BREAK_AND_ENTER`。**先量，不许先猜。**

## ⚠️ P3 复测（2026-09-21 13:2x）：**读数无效，不构成证据**

**做了什么**：`D-374`（图缺口）修复后，用**同一探针**（`single:mine_reach_probe`）复跑，想验证
「88 段绕远 = 那个缺口造成的」——按计划**只看 1× 档**。

**结果**：`1x reachable=0/13 · 100x reachable=0/4`，**但每个用例都是**
`status=UNREACHABLE nodes=1 movements=0 ms=0 diag=open set exhausted`。

**为什么无效（事实，不是推测）**：
- `nodes=1 / open set exhausted` 的含义是「**起点一步都走不出去**」，不是「不可达」；
- 直接读当前世界证实：起点 `432,84,428` 的**脚下 `432,83,428 = air`** ⇒ 起点**踩空** ⇒ 一次真实搜索都没发生；
- 根因：`新的世界 (2)` 这份真机存档**已被第五轮真机测试覆盖存盘**（region mtime = 09-21 12:36）⇒
  **round-4 的地形不再存在**；本轮实验用的是"世界已经不同"的副本。
  （母本 `run/world-pristine/r.0.0.mca` 的 mtime = 09-20 23:50，也不是 round-4 那份；
  当初 B 实验是把真机 `r.0.0.mca` **手工拷进** staged world 才复现的。）

**更危险的旧行为（已修）**：在这次无效运行里，探针**仍然**输出
`reproduced=true` 并给出结论「解释乙倾向成立：病在候选与边的可表示性」
—— 一个**基于 0 次真实搜索**的、与真相相反的自信结论（`silent-measurement-failure` 的教科书案例）。
**修法**（`MineReachProbeTask`）：新增**读数有效性判据** ——
① 起点必须可站（`canStandCentered`）；② 至少一次搜索真的扩展过（`nodes > 1`）。
任一不成立 ⇒ **响亮失败**（`FAILED 读数无效：start_standable=false realSearches=0/17`），不再输出结论。
反向对照：同一条无效世界重跑 ⇒ 由 `verdict=PASS(reproduced=true)` 变为 **`verdict=FAIL`** ✓。

**结论**：本实验的**原始结论（§四）仍然成立**（它当时是在正确的 round-4 副本上跑的）；
但**「88 段绕远是不是缺口造成的」这个问题，P3 没能回答**。要回答需要**一份冻结的 round-4 世界副本**，
或在一个**全新的、当场建场景**的深矿几何上重做（推荐后者：不依赖任何真机存档，可复现）。

**教训（方法论，已进本文）**：**对照实验必须在实验当时冻结世界副本** ——
指向 `ALICE_CLIENT_SAVE` 的复测会因为真机测试覆盖存档而**静默变成另一个实验**；
探针这类"只在特定世界状态下才有意义"的测量，**必须自己断言几何前提**（起点可站），
否则"没测到"会伪装成"测到了"。

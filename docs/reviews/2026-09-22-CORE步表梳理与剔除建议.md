## 4. 有异议 / 需要用户拍板的条目

**D1（最重要，独立于降级建议）—— `fall_execute` / `pillar_execute` 现在"不可能红"，这是缺陷不是特性。**
`CleanupWrappedTask.tick()`：内层返回 `FAILED` 时也置 `innerDone = true` 并 `cleanup()`（`CleanupWrappedTask.java:62-65`），而 `cleanup()` **无条件** `cleaned = true`（`:91`），终态判据是 `return innerDone && cleaned ? Status.DONE : Status.FAILED;`（`:71`）⇒ **内层红也返回 DONE**；电池只在 `status == Status.DONE` 时记 `PASS`（`RegressionBatteryTask.java:730-731`）。后果：这两步的 5 条 / 3 条判据**全部红掉**时，CORE 仍记 `PASS`；唯一能红的路径是抛异常（被 `RegressionBatteryTask.java:676-681` 抓成 FAIL）。
⇒ **建议**：(i) 两处最小修（把内层终态透传，或 `cleaned` 只在真拆成功时置真）；(ii) 无论修不修，这两步都降 EXTRA（它们是 D-280 的工具步，且 `pathing` 已覆盖同场景同坐标）。修法涉及代码 ⇒ **本报告只记录，未改**。

## 5. 剔除后的 CORE 步序影响

**结论：本提案只做"删除/降级"，不做"移位 ⇒ 存活步的相对次序逐字不变（0 处位移）。**

- 规则出处：R-2 迁移期反复使用的口径是「**CORE 步序逐字不变 / 步序 diff = 0 处差异**」作为**证明义务**，而不是可选建议 —— `docs/BATTERY_CURATION.md:296`（"六片全部原序落位（0 位移）…CORE 步序应逐字不变"）、`docs/BATTERY_CURATION.md:294`（"模块落点必须选'保住 CORE 步序'的那一侧"）、`docs/AI_DECISIONS.md:11963-11987`、`docs/AI_DECISIONS.md:12010-12011`、`docs/AI_DECISIONS.md:12125`、`docs/AI_DECISIONS.md:12388`（"既有 49 步零位移"）、以及 D-302「**顺序也是行为**，且 CORE 会**蒙对**」（`docs/AI_DECISIONS.md:11786-11800`）。`DeathModule.java:29-40` 把这条写成了模块级纪律。
- **逐对检查**：13 个降级项全部是"从 CORE 列表移除"，没有一项改为插入到别的位置；因此**存活 40 步之间的相对次序与今天完全一致**（把 `CORE(53)` 与 `CORE(40)` 两份名单按序做子序列比对，结果恰为恒等）。
- **唯一需要留意的两处"位置语义"（不是因为本提案，而是它们本来就有）**：
  1. `write_policy` **必须留在后段**（`WriteModule.java:24-26` + `RegressionBatteryTask.java:561`：它审计"本次电池此前所有写入"的归因样本）—— 删除它**前面**的步骤会**减少**它的样本量。本提案删掉的 13 项里，位于它前面的有：`fall_execute`、`pillar_execute`、`craft_action`、`craft_table`*、`craft_station`、`craft_probe_*`、`craft_station_*`、`machine_*`、`coarse_goal_prefix`（\* 若您采纳 D2 则 `craft_table` 保留）。⇒ **它的判据形状不变（`no_unregistered_requester` 断言的是"名单为空"，与样本数量无关），但样本数会变少**；这正是它 2026-09-21 假红过一次的那条（`run/headless-logs/20260921-114153-core.log`，`reason=no_unregistered_requester`）。**处置**：降级后必须复跑一次 CORE 并对比它的 SUMMARY，不能只看总判决。
  2. `mine_budget` 依赖"本步作用域在 `provision` 之前开好"（`MiningModule.java:169-170`，D-301）—— 本提案不动它的位置，不受影响。
- **明确声明**：**没有任何一对存活步改变相对次序**；因此本提案**不触发** D-302 意义上的"未证明的顺序变更"。

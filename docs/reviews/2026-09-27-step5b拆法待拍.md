## §2 六个拍点

### 拍点 1 · 边界（**原子单位是什么**）

| 方案 | 内容 | 代价 |
|---|---|---|
| **`1甲`** ⭐推荐 | **原子 = "一簇的一次作业"**（走到簇锚点 + 等这一簇被吸走 + 计数 + **该簇的锚点重试**）；**编排 = 候选收集 + 聚类 + 逐簇迭代 + 总预算 + 守恒交叉校验 + 摘要** | 与 `5a` 判 1「按语句切」同源：锚点重试与"等吸附"**共享同一套状态**（`sweepTicks` / `settleTicks` / 簇内成员）⇒ 切开会在两边各造一份状态 |
| **`1乙`** | 原子 = "**一次走位 + 等吸附**"（不含锚点重试，重试留编排） | 编排要读写原子内部状态（当前簇成员 / 剩余实体）⇒ 接口变胖 |
| **`1丙`** | **三段**：编排 / 一簇作业 / **吸附机制**（拾取盒几何 + 落定等待 + 守恒校验，类比 `MineBlockRunner`） | 多一个类；守恒校验跨段共享状态 |

### 拍点 2 · 切法与提交边界

| 方案 | 内容 | 代价 |

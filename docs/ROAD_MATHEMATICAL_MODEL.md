# 道路数学模型（Road Mathematical Model）

> 本文档完整记录 Alice 道路/通道规划背后的数学模型设计，覆盖当前已实现的「几何最短路径」与未来要做的「时间成本密度积分求最小值」。
> 相关代码：`road/RoadPlan.java`（路线拟合）· `road/RoadBuilder.java`（逐单元构建）· `road/RoadObstaclePolicy.java`（统一禁区）。
> 旧 `MineTask` 猜 blocker / 阶梯清障方案已归档，不参与本模型。

---

## 一、连续空间模型

### 1.1 可达性面

设目标方块为 A。定义「可挖掘站位面」为所有满足

```
AP ≤ R
```

的点 P 的集合，其中 R 是固定挖掘距离上限（原版 4.5 格）。R 有界，因此该面是 A 为中心的球面（或球面的一部分）。

面之外的空间在分析阶段统一设定为虚空或可挖掘阻碍方块：它既是可达性边界，也是后续路径规划的有效活动范围。真实场景中该面外的方块会进入代价场（见 §五），但**不改变几何最短路形状**。

### 1.2 最短路径基准

bot 位于 B。无禁挖区时，A 到 B 的最短路径是直线段 AB，欧氏距离 |AB|。它有两个作用：

- 是所有可行路径长度的**下界**；
- 是搜索的**admissible heuristic**（不低估，保证 A* 最优）。

### 1.3 禁挖区绕行：绷紧绳子模型

在 AB 之间放入不规则封闭区域（不可挖掘方块簇）后，最短路径变成：

```
A → 切点₁（直线段）
切点₁ → 切点₂（贴着障碍边界的弧）
切点₂ → B（直线段）
```

即「两段直线 + 一段弧」，且两段直线不再是 AB 的延长线。这等价于经典的**绷紧绳子 / taut string** 模型。性质：

1. **切点条件**：直线段在离开/接触障碍处与障碍边界相切；
2. **圆形障碍闭式解**：切线长 √(AO²−r²)，弧长 r·θ；
3. **非凸障碍只看凸包**：路径只贴凸包走，凹部被拉直跳过；
4. **多障碍推广**：A、B 与所有障碍顶点构成**可见性图（visibility graph）**，最短路即图上最短路。

空间里其它面/三维体只要不是硬障碍，只是填充物，不影响几何最短路——它们决定的是代价（§五）。

### 1.4 挖掘与放置统一

同一拟合曲线在体素化后可能穿过：

- 可挖掘方块 → 通道清理（挖掘操作）；
- 虚空 → 需要垫支撑（放置操作）。

因此挖掘与放置是同一通道模型的正反两面：实体格清、虚空格搭。

## 二、体素离散化

### 2.1 通道截面

bot 是玩家身高，两格高。以中心线支撑格为基准：

```
支撑格（脚踩，y）
净空格（身体，y+1）
净空格（头部，y+2）
```

即每单元 = 1 格支撑 + 2 格净空。支撑格已有实体方块则保留（`OPEN`），为空气则标记 `SUPPORT_PLACE`（放置圆石）；净空格为实体则标记 `CLEAR`（清理）。

### 2.2 阶梯切割与错位口

连续弧线首次拟合后，相邻中心线点高度差可能超过 1 格，无法实际通过，因此切割成**每步最多 1 格高差**的阶梯。

高度变化的相连两格存在「错位口」：若空腔只有两格高，跳跃衔接处实际通过空间会压缩到一格。因此**较低的那一格要再向上延伸一格**（`addEdgeClearance` 补 `above(2)`、`above(3)`），保证衔接处通过空间仍有足足两格。

### 2.3 水平邻接

- 水平路径以 4 邻（正交）为主，尽量拟合成直线/折线，拐弯处 4 邻；
- 允许 8 邻对角，但**对角必须伴随两个正交侧格检查**（两个侧格都安全才可通过），防止只有角点相接、玩家实际无法通过的拐角；
- 对角拐角额外拓宽两侧净空，保证数学连通 = 实际可走。

### 2.4 终点支撑保护

选中的两个方块是目标方块（不是支撑格）。最终支撑格必须位于目标方块正下方：

```
目标方块
↑
最后一格踮脚/支撑格
```

这样后续采集时目标掉落物有受控支撑面承接，不会掉进通道深处。目标簇场景（未来）则把簇整体近似为 AABB 长方体保护体，全局路线只到达长方体最底部的目标，螺旋/通道不得侵入长方体，簇内采集走局部规划。

## 三、统一禁区策略（RoadObstaclePolicy）

道路规划不能硬编码水/岩浆。所有路线原语共用同一策略：

| 类别 | 规则 | 原因 |
|---|---|---|
| 任何非空 FluidState（含模组流体） | 本体 + **三维一格 clearance**（3×3×3 膨胀） | 通道贴着液体擦过会淹/烧，必须隔一格 |
| 安全区方块/区域（SafeZoneData） | 仅本体（精确禁区） | 保护语义，不扩散 |
| 负硬度不可破坏方块（基岩等） | 仅本体 | 挖不动，绕行即可 |
| 高代价清障方块（黑曜石/哭泣黑曜石/强化深板岩） | 仅本体 | 可作为明确目标，但道路自动清障回避 |
| `#alice:road_forbidden` 数据标签 | 仅本体 | 后续模组方块经数据包扩展，不改算法 |

形式化：路径可见的禁区体积为

```
Forbidden = ExactForbiddenBlocks ∪ SafeZoneVolume ∪ Dilate(AllFluidVoxels, r=1)
```

普通移动寻路与道路规划使用不同意图（移动可贴液体旁过，通道必须隔一格），但**同一来源**（`BlockBreakSafety`/`SafeZoneData`）分类。

## 四、路线原语（当前实现）

### 4.1 普通弯曲路径（默认）

三维体素 A*（`shortestVoxelRoute`）：

- 节点 = 支撑格；
- 水平 4 邻 + 受侧格检查的 8 邻对角；
- 每步 `dy ∈ {-1, 0, +1}`，**禁止纯竖直移动**（`dx=dz=0` 时不得升降），因此不会产生竖井；
- 高度差不足时搜索自动向外借水平步长（搜索边界 margin=24），每步最多 1 格高差，把落差摊成坡道；
- 代价 = 路径长度 + 轻微转弯惩罚（0.08）+ 轻微升降惩罚（0.05），近似「绳子绷紧」；
- 启发式 = octile 水平距离（对角 √2）+ 垂直 ×1.05，保证 admissible。

### 4.2 2×2 螺旋楼梯（高差补偿）

当普通路径无解且 `vertical > horizontal + 4` 时启用（`SPIRAL_EXTRA=4`，给普通弯曲留容错）：

- 水平投影固定 `2×2`，四步一圈，每步水平位移 + `dy=±1`；
- 螺旋步数向上取整到 4 的倍数，多余高度由入口普通坡道消化；
- 每单元 = 1 格支撑 + **3 格净空**（转向/错位需要更高空间）；
- **入口外一格同样扩宽到 3 格净空**（后继是螺旋单元的普通单元 headroom=3），避免进入螺旋时顶头；
- 出口经过**一格水平缓冲**才接到目标正下方支撑格，且缓冲/支撑格不得落在螺旋 `2×2` 水平投影内（`terminalSegmentClear`）——末段不遮挡楼梯、不侵入目标。

### 4.3 构建执行（RoadBuilder）

蓝图按中心线单元逐格执行：

1. 处理当前单元（放圆石支撑、清通净空，**按当前世界状态判断**，不依赖规划快照）；
2. 等待 5 tick；
3. 扫描单元柱体及上方：沙/沙砾等 `FallingBlock` 只要下方无支撑即视为不稳定；
4. 不稳定则清理坠落方块、重做当前单元（不重复放置/挖掘）；
5. 稳定后才进入下一单元；连续 3 次不稳定则停止并报告。

## 五、时间成本密度积分求最小值（未来）

### 5.1 几何距离 ≠ 执行成本

当前实现最小化的是**路径长度**（几何距离）。真实执行成本还包括：

- 挖掘时间（方块硬度 / 工具速度，逐格不同）；
- 放置时间（虚空格搭路）；
- 移动时间（平地/上下坡/转角的 tick 成本）；
- 工具损耗（次要，见 §5.3）。

### 5.2 密度场与线积分

把挖掘成本和搭路成本作为**密度函数映射到三维空间**，得到标量成本场：

```
c(x,y,z) =
    0              空气/已可通行
    t_break(x,y,z) 可挖方块（挖掘时间）
    t_place(x,y,z) 虚空（搭路成本）
    ∞              禁区（§三）
```

关键观察：**通道截面恒定（1×2/1×3）**，因此执行成本不是三维体积积分，而是沿路径的线积分：

```
Cost(γ) = ∫_γ c(x,y,z) dl
```

最小化执行成本 = 求使线积分最小的曲线 γ——即**加权最短路**，数学上与费马原理（光在折射率场中走极值路径）同构。挖掘与放置的正反统一在同一个标量场中天然成立（同一位置要么是实体格（挖）、要么虚空（搭）、要么已通行（0））。

### 5.3 分层收敛（避免过早引入 NP-hard）

工具损耗与材料数量不是位置函数，而是**状态函数**（依赖路径历史）。一旦成本依赖历史，问题从加权最短路升级为**资源约束最短路（RCSP）**，属 NP-hard 量级。因此分层：

- **L0 纯时间成本**：`c = 挖掘/放置/移动时间`，位置相关 → 经典加权 A* 可解且最优；
- **L1 损耗线性近似**：每挖一块记固定损耗常数，并入密度场 → 仍位置相关；
- **L2 材料/耐久约束**：不进逐格搜索，放在决策层做预算检查/软惩罚，搜完再评估「这条通道买不买得起」。

真实玩家不会精确计算损耗，工具损耗优先级很低（调一点权重即可减少损耗）。因此第一优先级是 **L0 时间成本线积分最短路**，L2 作为外部过滤层，而不是一开始就上完整变分。

### 5.4 与当前实现的衔接

1. 保留当前几何最短路作为长度下界/启发式；
2. 在 `shortestVoxelRoute` 的代价函数中加入 `c(x,y,z)`（每步成本 = 移动成本 + 目标格挖掘/放置时间），仍保持 4/8 邻与 1 格高差约束；
3. 禁区权重 = ∞ 由 `RoadObstaclePolicy` 提供；
4. 螺旋作为结构化原语，其成本 = 固定几何成本 + 内部清理/搭路成本，可与普通路径在 L0 层比较选择；
5. L2 资源检查挂在任务/决策层，不进搜索器。

## 六、模型验证与验收

- 平面短距离、1～2 格水平 + 大高差、螺旋正反向、液体禁区、端点保护、沙砾稳定等待，逐项纳入道路专用回归（每项 ≤30 秒）；
- 记录：路线模式、单元数、螺旋占位、失败阶段、构建耗时；
- 验收硬约束：无脚下挖、无 >1 格自由落体、无纯竖直中心线、受保护/昂贵方块不被清障破坏、螺旋出口不侵入目标、末端缓冲存在、目标正下方支撑格存在。

6. **道路专用回归测试**与严格时间预算验收。

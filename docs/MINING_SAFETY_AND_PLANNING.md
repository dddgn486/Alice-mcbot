# 挖掘安全与目标规划（后续设计约束）

> 记录自客户端实测反馈。当前旧版阶梯/清障状态机已被判定为过渡实现；下一阶段采用 Baritone 1.20.1 的 break-aware movement/cost 模型重构，本文约束继续有效。

## 一、当前必须执行的约束

1. **禁止超过 1 格的垂直自由下落**：现有位置步进执行器不模拟重力，也没有返回路径证明。即使能跳进坑，也不代表能原路返回。
2. **拾取按可达性而非损耗率判断**：
   - 每 tick 使用掉落物实体实时坐标刷新三维距离；
   - 仅距离 bot 超过 64 格的掉落物可被放弃；
   - 64 格内无路径、路径失败或超时均应报告任务失败，不得以“损耗可接受”伪装为完成；
   - 拾取终点应保证进入实体触碰范围，而非只靠近其方块格；
   - 当前已实现受限兜底：下方掉落物无普通路径时，最多开凿 8 个侧向斜下方普通方块形成单格阶梯，每挖一步都重新走 A*；不挖脚下、安全区、不可破坏或高代价清障块。
3. **禁止原地垂直下挖**：bot 不得在当前脚位正上方直接破坏脚下承重方块。这是后续所有挖掘执行器的铁律，防止掉入不可返回空间、悬崖或流体；若该方块是明确任务目标，执行器必须先换到侧面合法站位，再从侧面挖掘，而非直接中止任务。
4. **从下往上挖的站位约束**：向上挖时应站在目标正下方，避免掉落物向不可控方向弹落。当前 `BotMiner` 站位策略需在后续安全里程碑中收紧并验收。

## 二、向下接近目标的两类方案（与搭路模块共同实现）

当目标位于下方且现有站位不可达时，不允许直接让 bot 自由落下。规划器比较以下方案：

### 2.1 挖通道下行

- 逐格挖出通道，直到出现合法挖掘站位；
- 必须遵守“禁止挖脚下”，因此采用侧向阶梯通道而不是竖井；
- 代价考虑：需破坏方块数量、工具耐久、保护区、流体风险、返回路径长度、掉落物回收率。

### 2.2 搭楼梯接近

- 放置方块形成可逆的单格高差楼梯；
- 代价考虑：所需建筑方块数量、放置面是否存在、临时方块回收、路径长度和环境风险；
- 属于未来“搭路/垫方块”模块，不在当前拾取修复中实现。

### 2.3 方案选择

1. 本地规则先排除违反安全区、流体、返回可达性和资源条件的方案；
2. 对可行方案计算确定性复杂度/成本，选择低成本方案；
3. 清障路线不得擅自纳入安全区、不可破坏方块（基岩等）或高代价方块（黑曜石等）；先换站位/绕行，所有替代路线均失败才报告不可达；
4. 只有规则无法区分或出现未知模组环境时才交给大模型兜底；
5. 两类方案均不可行才返回 `stand_unreachable`。

## 三、规则约束 + 大模型兜底

决策层采用混合策略，而不是把原始世界数据直接交给模型：

1. **本地硬规则**：安全区、禁止脚下挖掘、危险流体、工具/资源前置、可达性和返回路径；
2. **任务型感知过滤**：扫描数据按当前任务分类与优先级聚合，只把高价值候选、异常和方案摘要交给模型；
3. **本地评分**：距离、暴露面、站位可达性、预计清障数量、掉落保护成本、目标群价值；
4. **模型兜底**：只处理规则难以选择的目标级策略，不参与逐 tick 移动和破坏。

## 四、目标群识别与批量采集（后续）

类似连锁挖矿，将匹配目标构造成空间连通图：

- 相邻定义可按 6 邻接起步，按矿物类型/标签配置是否扩展至 18/26 邻接；
- 连通分量视为一个目标群；
- 群评分考虑：总价值、最近入口、暴露比例、预计路径/清障成本、危险与保护规则；
- 高层决策只选择一次目标群；同群内部由本地执行器持续采集，避免每挖一个方块就重新调用模型；
- 执行中只在环境重大变化、背包/工具不足或群已耗尽时重新决策。

## 五、掉落物保护（与放置模块共同实现）

挖掘前检查目标周边环境：

1. **目标下方悬空**：优先在下方放置临时承接方块，避免掉落坠入深坑；
2. **附近存在水/岩浆等流体**：除当前挖掘面外，确认目标其余相邻面被实体方块包裹；存在开口时先放块封堵；
3. 临时方块必须记录进任务作用域，任务结束后在安全条件允许时回收；
4. 岩浆、虚空、流水冲刷方向应进入风险评分和任务失败原因。

## 六、外力位移支持的复杂度评估

允许重力、爆炸、击退、流水等外力改变 bot 位置，需要独立的运动恢复子系统，至少包括：

- 预期位置/轨迹与实际位置偏差检测；
- 将实体位置重新锚定到合法脚位；
- 下落中、落地、游泳、被推动和受伤状态识别；
- 当前路径失效后的实时重规划；
- 当前位置到安全点/起点的返回可达性检查；
- 无法恢复时中止动作并上报，而不是继续按旧路径硬移动。

复杂度显著高于当前确定性格点步进，暂不为两格坑拾取提前引入。当前仍以“每步高差不超过 1 格、路径节点确定、外力视为异常”作为执行边界。

### 4. Q-B：**怎么算"提完了"？**

**[🤖 技术建议]**

**定义"提完了"**：

| 阶段 | "提完了"的标志 |
|---|---|
| **阶段 1 筛选** | **188 份件级摘要**全部产出 + 开发者全部看过 + 勾选出"需要精提的件" |
| **阶段 2 精提** | **筛出的件**全部产出节级摘要 + 开发者全部看过 + 勾选出"要提取的节" |
| **阶段 3 落地** | 勾选的节全部写入 `AI_DECISIONS.md` 或 `EXTRACTED_KNOWLEDGE.md` |

**门禁**：

```bash
# 新增门禁：check-extraction-status
# 检查：
# 1. 阶段 1：188 件是否都有摘要？
# 2. 阶段 2：筛出的件是否都有节级摘要？
# 3. 阶段 3：勾选的节是否都已落地？
```

**防止"永远提不完"**的机制：

1. ✅ **固定范围**：只提取 188 件（批 2..N 的存量），⛔ 不追加
2. ✅ **固定交付物**：每件必须产出"有/无价值内容"的二元判断
3. ✅ **门禁可验证**：摘要数量 = 188（阶段 1）/ 筛出的件数量（阶段 2）

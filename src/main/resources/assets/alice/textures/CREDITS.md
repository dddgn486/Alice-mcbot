# 贴图来源与署名

物品贴图取自开源贴图集 **unused-textures**（作者 **malcolmriley**），以 **CC-BY-4.0** 许可使用，
文件名与内容未作修改。**同类别**的常规物品共用一张类别贴图（下表一），彼此以物品名（tooltip）区分；
夹具/诊断类物品各有一张**独立**贴图（下表二），便于在快捷栏里一眼区分。

- 来源：https://github.com/malcolmriley/unused-textures
- 许可：CC-BY-4.0 <https://creativecommons.org/licenses/by/4.0/>
- 作者：malcolmriley

# 软路径测试工具：游戏内实体交互（右键寻路 / Shift+右键寻路+挖掘）

- 任务类型：规划（浅调研 + 实施路线）
- 提出人：用户
- 日期：2026-08-24
- 当前 baseline：`2298dd3`（P1 已实施，CLIENT_TEST_PENDING）

## 用户需求

增加游戏内软路径测试工具，参考现有 `transfer_endpoint_selector`（金斧）和 `interface_scanner`（钻石铲）的交互模式：
- **右键点击方块**：软路径寻路到目标（SoftPathProbeTask）
- **Shift+右键点击方块**：软路径寻路 + 挖掘目标（新增：SoftPathProbeTask → MineTask，或统一 SoftPathMineTask）

**设计原则**（用户明确）：
- 避免精确坐标参数或多参数指令
- 游戏内实体测试物品（右键交互）
- 寻路和寻路+挖掘可以做在一个工具上（Shift 区分）

## 现有工具参考

| 工具 | 物品 ID | 外观材质 | 交互模式 | 功能 |
|---|---|---|---|---|
| `interface_scanner` | `alice:interface_scanner` | 钻石铲 | 右键方块 | 只读扫描箱子 |
| `soft_path_probe_selector` | `alice:soft_path_probe_selector` | 指南针 | 右键方块（support） | 软路径寻路到 support.above()，不挖掘 |
| `transfer_endpoint_selector` | `alice:transfer_endpoint_selector` | 金斧（stick 材质） | 右键 dest / Shift+右键 source | 转移端点选择 |

**现状**：`soft_path_probe_selector` 只支持右键寻路，不支持 Shift+右键挖掘。

## 规划任务目标

输出浅调研 + 实施路线（`.alice-supervision/research/soft-path-test-tool-plan-20260824.md`）：

1. **方案选择**：
   - 方案 A：扩展现有 `SoftPathProbeSelector`，增加 Shift 判定 + 挖掘逻辑
   - 方案 B：新增独立工具 `soft_path_mine_selector`（与 probe 分离）
   - 方案 C：统一工具 `soft_surface_test_selector`（右键 probe / Shift+右键 mine）

2. **交互设计**：
   - 点击目标：support 方块（foot = support.above()）还是直接点 foot？
   - Shift+右键挖掘：是挖掘点击的方块，还是寻路到 foot 后挖掘 foot？
   - 失败反馈：chat 消息 + 日志

3. **任务链**：
   - 右键：调用 `BotManager.assignSoftPathProbe(bot, target)`（已有）
   - Shift+右键：调用什么？
     - 选项 1：先 `assignSoftPathProbe(target)` → 完成后自动接 `assignMine(target)`（需改 BotManager 支持任务链？）
     - 选项 2：新增 `assignSoftPathMine(bot, target)`（统一任务：软路径寻路 + 到达后挖掘）
     - 选项 3：直接 `assignMine(target)`（MineTask 内部判定用软路径还是硬路径？）

4. **冻结边界守护**：
   - P1 只允许 SoftPathProbeTask/FollowTask 使用 SOFT_SURFACE
   - MineTask 当前固定 HARD_PATH（`docs/HANDOVER.md` R30、`docs/SUPERVISION_PROTOCOL.md` 冻结边界）
   - **Shift+右键挖掘不能让 MineTask 偷接入 SOFT_SURFACE**（除非用户批准 P2-P5）

5. **实施范围**：
   - 改动文件：`SoftPathProbeSelector.java`（或新增文件）、`AliceItems.java`（若新增物品）、`BotManager.java`（若新增 assign 方法）
   - 不改：P1 的 SoftPathProbeTask/FollowTask、MineTask 的 HARD_PATH、PathExecutor

6. **验证矩阵**：
   - 服务端：compileJava、既有 suites PASS
   - 客户端：T1（右键寻路）、T2（Shift+右键寻路+挖掘）、T3（隔离：普通 `/alice mine` 仍 HARD_PATH）

7. **停止条件**：
   - Shift+右键挖掘需要改 MineTask 接入 SOFT_SURFACE（违反冻结边界）
   - 任务链需要改 BotManager 核心调度（超出测试工具范围）
   - 用户不批准方案

## 禁止事项

- 不让 MineTask 接入 SOFT_SURFACE（P1 只允许 SoftPathProbeTask/FollowTask）
- 不改 PathExecutor/BotMiner/DropCollectionTask/道路/隧道

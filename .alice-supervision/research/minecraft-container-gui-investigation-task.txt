# Minecraft 容器 GUI 正确实现深度调研（联网）

## 调研目标

解决 Alice Bot Inventory GUI 的两个严重缺陷：①GUI 面板背景/边框完全不显示（自绘纯色面板失败）；②拿取物品就消失（quickMoveStack 交互仍失败）。需要联网调研 Minecraft/Forge 容器 GUI 的**正确、成熟**实现方式。

## 问题背景

**当前实现已连续两次失败（f0ef6fc → f4bf79a）**：
- `f0ef6fc`：用 `generic_54.png` vanilla 纹理 + 自定义 4x9 坐标 → 槽位与背景错位、装备槽未渲染
- `f4bf79a`：改用 `graphics.fill` 自绘纯色面板（`PANEL_TOP=0x3F3F3F`）+ 槽位格 → **面板完全不显示**、拿取物品消失

**截图证据**（`run/screenshots/2026-08-23_02.54.46.png`）：
- 标题 "Bot Inventory: tango" 在最顶部
- 玩家背包槽位格子**悬浮半空、无面板包裹**（右上 27 格 + 左下 hotbar 9 格）
- "物品栏"标签在左侧（AbstractContainerScreen 自动绘制）
- 槽位格子是散的，没有一个统一的 GUI 面板背景/边框

**当前 Screen 方案**（`BotInventoryScreen.java`，f4bf79a）：
```java
@Override
protected void renderBg(GuiGraphics graphics, float delta, int mouseX, int mouseY) {
    int x = (width - imageWidth) / 2;
    int y = (height - imageHeight) / 2;
    graphics.fill(x, y, x + imageWidth, y + imageHeight, PANEL_TOP);  // 0x3F3F3F 暗灰
    graphics.fill(x, y, x + imageWidth, y + 1, BORDER);
    ...
    for (int i = 0; i < getMenu().slots.size(); i++) {
        var slot = getMenu().slots.get(i);
        int sx = x + slot.x - 1;
        int sy = y + slot.y - 1;
        graphics.fill(sx, sy, sx + 18, sy + 18, SLOT_BG);  // 槽位格
    }
}
```

## 关键问题

1. **为什么自绘面板不显示？** `renderBg` 的 `graphics.fill` 是否被 `renderBackground`（半透明遮罩）覆盖？渲染时序/坐标错误？颜色太暗不可见？`AbstractContainerScreen.render()` 的调用链中 `renderBg` 是否正确被调用？
2. **槽位格子为什么散开无面板？** 槽位坐标（bot armor/offhand/main/hotbar + 玩家槽）是否正确聚合在一个标准面板区域内？
3. **拿取物品消失的根因？** 是 `quickMoveStack`/`clicked` 逻辑缺陷，还是 GUI 背景缺失导致用户点击错位（点了实际不存在的槽位）？
4. **正确做法是什么？** 应该用哪个 vanilla 纹理（`inventory.png`/`generic_54.png`）？槽位坐标如何与之严格对齐？

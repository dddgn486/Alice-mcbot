# Bot 手持物品渲染调试任务

## 问题

用户测试 `a8b84b4`（fix: sync bot main hand equipment for entity rendering）后，Bot 手持物品仍然不可见。

## 当前代码

```java
// ChestBotTransferPrimitive.java:228-240
private static void syncBotInventorySlots(Inventory inventory) {
    if (!(inventory.player instanceof ServerPlayer bot)) return;
    for (int i = 0; i < inventory.getContainerSize(); i++) {
        bot.connection.send(new ClientboundContainerSetSlotPacket(-2, 0, i, inventory.getItem(i)));
    }
    // Sync main hand equipment for entity rendering
    ItemStack mainHandStack = inventory.getItem(inventory.selected);
    bot.connection.send(new ClientboundSetEquipmentPacket(
            bot.getId(),
            List.of(Pair.of(EquipmentSlot.MAINHAND, mainHandStack))
    ));
}
```

## 可能的根因

1. **Packet 未发送**：`bot.connection.send()` 失败或被忽略
2. **Entity ID 错误**：`bot.getId()` 返回值不正确
3. **槽位错误**：`inventory.selected` 不是实际持有物品的槽位
4. **ItemStack 为空**：`mainHandStack` 是 `ItemStack.EMPTY`
5. **客户端未应用**：Forge equipment sync 需要额外步骤（如广播到所有玩家）

## 诊断任务

创建 active plan，添加诊断日志到 `syncBotInventorySlots()`，验证：
1. 方法是否被调用
2. `bot.getId()` 的值
3. `inventory.selected` 的值
4. `mainHandStack` 的内容（是否为空）
5. Packet 是否成功发送

日志输出格式：
```java
BotLog.info("[EQUIPMENT_DEBUG] syncBotInventorySlots called: botId={}, selected={}, mainHand={}", 
    bot.getId(), inventory.selected, mainHandStack);
```

## 备选方案

如果诊断显示 packet 正确发送但客户端不应用，尝试：
1. 使用 `ServerPlayer.setItemSlot(EquipmentSlot.MAINHAND, stack)` 代替直接发送 packet
2. 广播 packet 给所有玩家（`bot.getServer().getPlayerList().broadcastAll(...)`）
3. 强制触发客户端更新（`bot.refreshDimensions()`）

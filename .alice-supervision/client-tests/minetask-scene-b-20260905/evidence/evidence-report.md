# MineTask 场景 B 客户端验收证据

日期：2026-09-05

测试环境：PCL 标准 Forge 1.20.1 / Forge 47.4.10 / Alice / WorldEdit 7.2.15

入口：`/function alice_test:scene_b` 和 `alice:mining_scene_b_tester`

## 用户观察

用户确认场景 B 符合预期。Bot 没有绕过石墙，而是挖开障碍后继续移动并完成目标挖掘。

## 服务端关键事实

- 场景起点：`(-3,64,0)`
- 目标：`(0,64,3)`
- 墙前规划站位：`(-3,64,0)`
- 目标侧最终站位：`(0,65,3)`
- 有限清障：挖掉 `(-3,65,1)`，记录为 `局部清障(1/2)`
- 清障后继续原目标：`清障完成`
- 任务终态：`COMPLETED`
- 结果码：`done`
- 任务级恢复次数：`0`

完整日志保存在 `latest.log`，筛选后的关键行保存在 `scene-b-key-lines.log`。

## 结论

场景 B 达到 `USER_ACCEPTED`。已验证封闭边界下 Bot 不绕墙，而是执行有限目标访问清障，再完成目标挖掘。

## 边界

本证据不证明任务级重规划通过。`recoveryAttempts=0` 是预期结果，因为本场景验证的是现有目标访问清障，不是 MineTask 的一次任务级重规划。

## Objective

修复 Bot Inventory GUI 的"拿取物品消失"：PICKUP 触摸 bot 槽后强制同步 bot 槽位到玩家客户端（setChanged → broadcastChanges）。

## Allowed Scope

**只改** `src/main/java/com/dddgn/alice/gui/BotInventoryMenu.java`

### 修复要点（基于源码诊断 scheme A）

修改 `clicked()` 方法：PICKUP 且触摸 bot 槽（slotId < BOT_SLOT_CAP）时，执行后强制遍历 bot 槽 `setChanged()` 触发 `broadcastChanges()` 同步：

```java
@Override
public void clicked(int slotId, int button, ClickType clickType, Player player) {
    boolean botSlot = slotId >= 0 && slotId < BOT_SLOT_CAP;
    if (taskActive && botSlot) {
        return;  // 只读保护
    }
    super.clicked(slotId, button, clickType, player);
    // PICKUP 触摸 bot 槽 → 强制同步 bot 槽位到玩家客户端（修复"拿取消失"）
    if (clickType == ClickType.PICKUP && botSlot) {
        for (int i = 0; i < BOT_SLOT_CAP; i++) {
            this.slots.get(i).setChanged();
        }
    }
}
```

## Objective

彻底重写 Bot Inventory GUI，复用原版 `InventoryMenu`（玩家背包菜单）的槽位几何和 Slot 类型，解决拿取消失、放入两倍、文字同色、布局混乱。

## Allowed Scope

**只改** `src/main/java/com/dddgn/alice/gui/BotInventoryMenu.java` + `client/gui/BotInventoryScreen.java`（+ 新增 BotArmorSlot/BotOffhandSlot 子类，可在 BotInventoryMenu 内实现）

### 修复要点（基于源码调研，src/research/vanilla-inventory-menu-source-20260823.md）

1. **armor/offhand 槽用自定义 Slot 子类**（对齐原版 InventoryMenu$1/$2）：
   - `getMaxStackSize()=1`
   - `mayPlace()=stack.canEquip(slotType, bot)`（canEquip 检查）
   - `mayPickup()`（绑定诅咒检查）
   - `setByPlayer()`（触发 onEquip）
2. **quickMoveStack 按原版 index 分区语义**：
   - `original=stack.copy()` 保存移动前副本
   - bot 槽（0..BOT_SLOT_CAP）→ 玩家背包；玩家槽 → bot 背包
   - 若物品是装备，优先移动到对应 bot armor/offhand 槽
   - 移动后用 `slot.setByPlayer(ItemStack.EMPTY)`（而非 set()）
   - 返回 `original`（移动前副本）
3. **Screen 背景用 `inventory.png`（176×166）**：
   - `imageWidth=176, imageHeight=166`（标准玩家背包高度，若含玩家背包则适当增大但用标准几何 + 有效 alpha）
   - `renderBg` 用 `graphics.blit(INVENTORY_TEXTURE, ...)` 或自绘面板但坐标严格对 vanilla 几何
   - **标题/标签颜色**：确保可见（不与被板同色，如用标准 0x404040 或更大 contrast）
4. **任务保护集成**：`quickMoveStack`/`clicked` 中 `taskActive && index < BOT_SLOT_CAP` 时中断（只读）

**必要时仅准确更新**：`docs/HANDOVER.md` 记录重写

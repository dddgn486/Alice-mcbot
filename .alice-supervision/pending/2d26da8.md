### 方案 A（推荐）：尝试 `setItemSlot()` 方法

替换 `syncBotInventorySlots()` 的 equipment 同步部分：

```java
private static void syncBotInventorySlots(Inventory inventory) {
    if (!(inventory.player instanceof ServerPlayer bot)) return;
    
    // 现有：同步所有 inventory 槽位（GUI 数据）
    for (int i = 0; i < inventory.getContainerSize(); i++) {
        bot.connection.send(new ClientboundContainerSetSlotPacket(-2, 0, i, inventory.getItem(i)));
    }
    
    // 新方案：使用 setItemSlot() 代替直接发送 packet
    ItemStack mainHandStack = inventory.getItem(inventory.selected);
    BotLog.info("[EQUIPMENT_DEBUG] Syncing equipment: botId={}, selected={}, mainHand={}", 
        bot.getId(), inventory.selected, mainHandStack);
    
    // 方案 A：使用 ServerPlayer.setItemSlot()（触发自动同步）
    bot.setItemSlot(net.minecraft.world.entity.EquipmentSlot.MAINHAND, mainHandStack);
}
```

**原理**：`ServerPlayer.setItemSlot()` 可能内部触发更完整的同步逻辑，而直接发送 `ClientboundSetEquipmentPacket` 可能缺少某些步骤。
